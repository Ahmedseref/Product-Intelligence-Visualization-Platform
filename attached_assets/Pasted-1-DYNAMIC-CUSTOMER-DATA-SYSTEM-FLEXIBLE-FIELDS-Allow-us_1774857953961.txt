3) 💰 ADVANCED FINANCIAL ENGINE (VERY IMPORTANT)
🎯 الهدف:

User can create custom financial calculations, not only total

🧠 STRUCTURE

Create table:

proforma_financials
id
proforma_id
name (e.g., Discount, VAT, Shipping)
type (add / subtract)
value_type (percentage / fixed)
value
order_index
⚙️ CALCULATION ENGINE

Process in order:

subtotal = sum(products)

for item in financials:
    if type == "add":
        subtotal += value
    elif type == "subtract":
        subtotal -= value

If percentage:

value = subtotal * (percentage / 100)
✅ EXAMPLES USER CAN ADD:
Discount (-10%)
VAT (+20%)
Shipping Cost (+$500)
Prepayment (-$1000)
Customs Fees (+)
🖥️ UI
Button: “+ Add Calculation”
Fields:

Add / Subtract (toggle)
Percentage / Fixed
Value
Drag to reorder priority
