Single canvas, two-column layout:
- Left column (controls): all editable fields — customer, shipping, products, financial calculations, notes
- Right column (live preview): a read-only invoice document that updates in real-time as the user types on the left
- No separate "Preview" screen. No separate "Edit Details" screen. No modal popups for editing.
- The invoice list screen still exists as the entry point — clicking an invoice or "+ New Proforma" opens the single-canvas editor

### Right column (live preview, ~60% width, sticky top)
A styled document that mirrors the printed invoice. Updates in real time via React state — no API calls needed for preview updates.

The document structure (top to bottom):
1. Header row: Company info left (from proforma_settings), invoice title + ID + date right
2. Bill & ship to block (customer info) | Meta strip (terms, currency, ports, incoterms — from left column fields)
3. Line items table: Description of goods | Unit price | QTY | Unit | Total
4. Financial calculations summary: each step as a line (name + computed amount), then Final Total bold
5. Bank details (monospace, if filled)
6. Notes / footer (if filled)

All values in the preview come from React state — they update as the user types. No save required to see changes.

## Financial calculation engine
Create a pure function computeFinancials(items, calcSteps, currency):

```typescript
function computeFinancials(items, calcSteps, currency) {
  const subtotal = items.reduce((sum, item) => sum + (item.qty * item.unitPrice), 0);
  let running = subtotal;
  const steps = calcSteps.map(step => {
    const amount = step.valType === 'pct' 
      ? running * (step.value / 100) 
      : step.value;
    const signed = step.type === 'sub' ? -amount : amount;
    running += signed;
    return { ...step, computedAmount: signed, runningTotal: running };
  });
  return { subtotal, steps, finalTotal: running };
}
```

This function is called on every state change. Its output drives both the left column (computed amounts per step) and the right column (financials preview).

## State management
Use a single invoice state object in React:

```typescript
interface InvoiceState {
  customerId: string;
  currency: string;
  date: string;
  termsOfPayment: string;
  termsOfDelivery: string;
  portOfLoading: string;
  placeOfDestination: string;
  finalDelivery: string;
  countryOfOrigin: string;

  items: InvoiceItem[];
  calcSteps: CalcStep[];
  notes: string;
  bankDetails: string;

```

Every input onChange updates this state. The preview derives everything from this state. Save calls PATCH /api/proformas/:id (or POST for new) with the full state.
