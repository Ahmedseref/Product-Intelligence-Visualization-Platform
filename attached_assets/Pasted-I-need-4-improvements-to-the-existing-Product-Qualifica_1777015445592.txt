## Fix 2 — Layer Position: new qualification field

Add a 5th qualification attribute called Layer Position. This is the most important field — it controls which other fields are shown and what substrate options are available.

### Schema change (shared/schema.ts)
Add column to product_qualification_tags table:
- layer_position: varchar(50) nullable

Options (add to qualification_vocabularies as vocab_type = 'layer_position'):
- value: 'primer', label: 'Primer' — applied directly to structural substrate
- value: 'base_coat', label: 'Base Coat' — applied over primer
- value: 'intermediate', label: 'Intermediate Coat' — applied over base coat or primer
- value: 'topcoat', label: 'Topcoat / Sealer' — final exposed layer
- value: 'standalone', label: 'Standalone' — used independently, not in a system stack

Run npm run db:push after schema change.

### Conditional field logic based on Layer Position:

When layer_position = 'primer':
- Substrate: show structural options (Concrete, Steel, Wood, Screed, Asphalt, Ceramic, Existing Coating) — normal multi-select
- Humidity: show — relevant
- Duty: show — relevant
- Finish: HIDE completely — not applicable for primers

When layer_position = 'base_coat' or 'intermediate':
- Substrate: show only "Over Primer" as a fixed non-editable label — no dropdown needed. Save substrate_types = ['Over Primer'] automatically
- Humidity: show — relevant
- Duty: show — relevant
- Finish: show — it can be the final layer 

When layer_position = 'topcoat':
- Substrate: show only "Over Base Coat" or "Over Primer" as fixed options (2 options only)
- Humidity: show — relevant
- Duty: show — relevant
- Finish: SHOW and mark as required — this is the critical field for topcoats

When layer_position = 'standalone':
- Substrate: show structural options (Concrete, Steel, Wood, Screed, Asphalt, Ceramic, Existing Coating)
- Humidity: show
- Duty: show
- Finish: show — relevant

When layer_position = null (not set yet):
- Show all fields as today (existing behavior, no regression)
- Show a gentle prompt: "Set Layer Position to get smarter field options"

### UI changes in the qualification table rows:
- Add Layer Position as the FIRST dropdown column (before Substrate) in the qualification table
- When Layer Position is selected, immediately hide/show/change the other columns on that row
- Hidden fields show a grey "N/A" label in their column cell instead of a dropdown
