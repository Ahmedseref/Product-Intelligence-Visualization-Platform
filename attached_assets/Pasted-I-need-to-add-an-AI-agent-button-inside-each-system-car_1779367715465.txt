## New server endpoint

POST /api/systems/:id/ai-fill

This endpoint:
1. Fetches the full system record including all layers, products, 
   qualification tags, and system parameters
2. Fetches ALL other systems in the database as reference context 
   (names and descriptions only — to help with tone consistency)
3. Calls the Anthropic API with the prompt below
4. Returns the generated content — does NOT auto-save anything
5. The user reviews and clicks Save explicitly

Request body:
{
  sections: ['description', 'recommendation', 'warnings']
  // user can request specific sections or all
}

Response:
{
  description: string,        // 2-4 sentences, customer-facing
  recommendation: string,     // 1-3 sentences, technical tip
  warnings: string[],         // optional cautions
  confidence: 'HIGH' | 'MEDIUM' | 'LOW',
  reasoning: string           // why the agent wrote what it wrote
}
